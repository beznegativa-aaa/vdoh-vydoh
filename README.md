# Вдох Выдох

Шуточное Android-приложение для "дыхания" 😄

## Описание
Простое приложение с одной большой кнопкой. Нажимаешь — делаешь "вдох", нажимаешь снова — делаешь "выдох". 
Кнопка анимируется, телефон вибрирует, счетчик считает вдохи.

## Как запустить

1. Открой проект в Android Studio
2. Подожди, пока Gradle синхронизируется
3. Подключи Android-устройство или запусти эмулятор
4. Нажми Run (зеленый треугольник)

## Требования
- Android Studio Arctic Fox или новее
- Android SDK 24+ (Android 7.0)
- Kotlin 1.9.20
