# Вдох Выдох

Функциональное описание мобильного приложения для управления дыхательными циклами

## Описание
# Функциональная спецификация

## 1. Назначение

Мобильное приложение предназначено для последовательного ручного управления фазами дыхательного цикла посредством одного основного интерактивного элемента.

Приложение реализует строго определенную последовательность состояний:

**Ожидание → Вдох → Выдох → Вдох → Выдох**

Пользователь не запускает отдельные процессы для вдоха и выдоха. Каждое нажатие на основную кнопку переводит приложение в следующее состояние цикла.

Основной интерфейс намеренно ограничен одним центральным элементом управления, текстовым индикатором текущего состояния и счетчиком выполненных вдохов.

---

## 2. Исходное состояние

При первоначальном запуске приложения устанавливается состояние:

**Текст состояния:**

> Ты пока не дышишь

**Основная кнопка:**

> Вдох

Кнопка находится в исходном размере.

Счетчик в нижней части экрана отображается в формате:

> Сделано вдохов: 0

Приложение находится в состоянии ожидания первого пользовательского действия.

---

## 3. Состояние «Вдох»

При первом нажатии на основную кнопку выполняются следующие операции:

1. Приложение фиксирует пользовательское взаимодействие.
2. Текущее состояние изменяется на **INHALE**.
3. Текст состояния изменяется на:

   > Вдох...
4. Основная кнопка изменяет надпись с **«Вдох»** на **«Выдох»**.
5. Запускается плавная анимация увеличения кнопки.
6. Выполняется легкая тактильная обратная связь посредством `HapticFeedback`.
7. Приложение ожидает следующего нажатия пользователя.

Увеличение кнопки должно выполняться средствами Compose Animation. Изменение размера не должно происходить мгновенно — переход должен быть визуально плавным.

---

## 4. Состояние «Выдох»

При повторном нажатии на основную кнопку:

1. Приложение фиксирует пользовательское взаимодействие.
2. Текущее состояние изменяется на **EXHALE**.
3. Текст состояния изменяется на:

   > Выдох...
4. Основная кнопка изменяет надпись с **«Выдох»** обратно на **«Вдох»**.
5. Запускается плавная анимация уменьшения кнопки до исходного размера.
6. Выполняется легкая тактильная обратная связь посредством `HapticFeedback`.
7. Завершается один полный дыхательный цикл.
8. Счетчик выполненных вдохов увеличивается на единицу.

После завершения данного перехода приложение готово к следующему вдоху.

---

## 5. Счетчик дыхательных циклов

В нижней части основного экрана постоянно отображается счетчик:

> Сделано вдохов: X

Где **X** — количество завершенных дыхательных циклов.

Начальное значение:

> Сделано вдохов: 0

После последовательности:

**Вдох → Выдох**

значение становится:

> Сделано вдохов: 1

После следующей последовательности:

**Вдох → Выдох**

значение становится:

> Сделано вдохов: 2

Таким образом, счетчик **не увеличивается при нажатии «Вдох»**.

Единица добавляется только после перехода из состояния **«Вдох...»** в состояние **«Выдох...»**, то есть после завершения полного цикла.

---

## 6. Состояния интерфейса

### STATE_IDLE

Текст:

**Ты пока не дышишь**

Кнопка:

**Вдох**

Размер кнопки:

**исходный**

Счетчик:

**Сделано вдохов: X**

---

### STATE_INHALE

Текст:

**Вдох...**

Кнопка:

**Выдох**

Размер кнопки:

**увеличенный**

Анимация:

**плавное увеличение**

Haptic Feedback:

**однократный легкий отклик при переходе в состояние**

---

### STATE_EXHALE

Текст:

**Выдох...**

Кнопка:

**Вдох**

Размер кнопки:

**исходный**

Анимация:

**плавное уменьшение**

Haptic Feedback:

**однократный легкий отклик при переходе в состояние**

После перехода счетчик увеличивается на **1**.

---

Полный пользовательский сценарий должен выглядеть следующим образом:

`Ты пока не дышишь`
`[ Вдох ]`
`Сделано вдохов: 0`

↓

**Нажатие**

`Вдох...`
`[ Выдох ]`
Кнопка увеличивается
Haptic Feedback

↓

**Нажатие**

`Выдох...`
`[ Вдох ]`
Кнопка уменьшается
Haptic Feedback
Счетчик: `Сделано вдохов: 1`

↓

**Нажатие**

`Вдох...`
`[ Выдох ]`
Кнопка увеличивается
Haptic Feedback

↓

**Нажатие**

`Выдох...`
`[ Вдох ]`
Кнопка уменьшается
Haptic Feedback
Счетчик: `Сделано вдохов: 2`

Цикл повторяется неограниченное количество раз.

## 8. Техническая реализация

Приложение должно быть реализовано на **Jetpack Compose**.

Состояние интерфейса должно определяться единым источником состояния, исключающим рассинхронизацию текста, надписи кнопки, размера кнопки и счетчика.

Для анимации размера основной кнопки использовать Compose Animation API, например `animateDpAsState` либо эквивалентный механизм.

Логика должна быть построена таким образом, чтобы изменение состояния автоматически приводило к соответствующему обновлению UI.

Условная модель:

```text
IDLE
  ↓ [нажатие]
INHALE
  ↓ [нажатие]
EXHALE
  ↓
INHALE
  ↓
EXHALE
```

При переходе:

**IDLE → INHALE**

изменяются:

* текст;
* надпись кнопки;
* размер кнопки;
* тактильная обратная связь.

При переходе:

**INHALE → EXHALE**

изменяются:

* текст;
* надпись кнопки;
* размер кнопки;
* тактильная обратная связь;
* значение счетчика.

Ключевое требование: **счетчик увеличивается исключительно при завершении перехода «Вдох → Выдох».**

---

## 9. Поведение при повторном использовании

После завершения каждого цикла приложение не должно возвращаться в состояние **«Ты пока не дышишь»**.

Текст **«Ты пока не дышишь»** используется исключительно для первоначального состояния приложения.

После первого запуска дыхательного цикла приложение продолжает работать в последовательности:

**Вдох → Выдох → Вдох → Выдох...**

без дополнительных промежуточных состояний.

---

## 10. Итоговая спецификация

Приложение должно реализовывать предельно простой и детерминированный сценарий:

**Один экран. Одна основная кнопка. Два рабочих состояния. Одна последовательность переходов. Один счетчик.**

Первоначально:

> **Ты пока не дышишь**
> **[ Вдох ]**
> **Сделано вдохов: 0**

После нажатия:

> **Вдох...**
> **[ Выдох ]**

После следующего нажатия:

> **Выдох...**
> **[ Вдох ]**
> **Сделано вдохов: 1**

Каждое последующее нажатие продолжает установленную последовательность, а каждое завершение пары **«Вдох → Выдох»** увеличивает счетчик на единицу.


## Как запустить

1. Открой проект в Android Studio
2. Подожди, пока Gradle синхронизируется
3. Подключи Android-устройство или запусти эмулятор
4. Нажми Run (зеленый треугольник)

## Требования
- Android Studio Arctic Fox или новее
- Android SDK 24+ (Android 7.0)
- Kotlin 1.9.20
